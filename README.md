# Enter Text

Android-приложение для Redmi Watch 4: отправляет ваши сообщения, распознанный рукописный
текст с фото и текст, написанный пальцем, в виде уведомлений. Mi Fitness пересылает их на часы.

## Сборка APK
Загрузите содержимое папки в репозиторий GitHub (вместе с `.github/workflows/build.yml`),
дождитесь вкладки Actions → готовый `EnterText-APK` внизу страницы сборки.

## Первая настройка
1. Запустите Enter Text, разрешите уведомления, отправьте тестовое сообщение.
2. В Mi Fitness включите пересылку уведомлений для Enter Text.
3. Вкладка «Настройки» → «Тест: сколько влезает на часы». Поставьте ползунок на последнее
   число, которое видно на часах до «…». Тогда сообщения будут делиться без обрезки.

## Распознавание почерка
- «Рукопись»: пишете пальцем или стилусом по одной строке, офлайн (ML Kit, русский и английский).
  Языковая модель скачивается один раз.
- «Фото»: лучший результат даёт Claude. Вставьте ключ API (console.anthropic.com) в «Настройки».
  Без ключа работает локальный Tesseract, он плохо читает почерк.
