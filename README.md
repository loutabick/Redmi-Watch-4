# WatchPing

Android-приложение: отправляет ваши сообщения и текст с фотографий (OCR, русский + английский)
в виде уведомлений на телефоне. Mi Fitness пересылает их на Redmi Watch 4.

## Сборка
1. Установите Android Studio и откройте папку `WatchPing`.
2. Дождитесь Gradle Sync (он сам скачает Gradle и библиотеки; если предложит обновить версии — соглашайтесь).
3. Подключите Nothing Phone 2 по USB (включите отладку по USB) и нажмите Run.

## Настройка пересылки на часы
1. Запустите WatchPing, разрешите уведомления и отправьте тестовое сообщение
   (приложение должно появиться в списке приложений Mi Fitness).
2. В Mi Fitness откройте своё устройство → уведомления/напоминания → уведомления приложений
   и включите WatchPing.
3. В настройках Android дайте Mi Fitness доступ к уведомлениям и отключите для него экономию батареи.

## Использование
- Введите заголовок и текст → «Отправить на часы».
- «Выбрать фото» (или «Поделиться» → WatchPing из галереи): при первом запуске приложение
  скачает языковые данные Tesseract (~5 МБ), затем распознает текст и вставит его в поле.
  Проверьте и отправьте. Длинный текст автоматически делится на несколько уведомлений.
